# 東京23区 子連れイベント AIガイド（新サイト・隔離プロトタイプ）

既存の `tokyo-weekend-events` を壊さず、別サイトとして切り出すための新実装です。

## 目的

- チャッピーが東京23区を横断して子連れ参加候補イベントを探索する
- 区ごとの確認状況を可視化する
- 23区・キーワードで検索できる
- 既存サイトの「コピペ用リスト」の操作感と出力順を維持する
- AI向けの追加情報を増やしても、コピペ出力を壊さない

## 現行サイトへの影響

このディレクトリは、現行の公開対象 `site/` と root の `.github/workflows/deploy.yml` から独立しています。
現在の GitHub Pages は root の `site/` だけをアップロードするため、このプロトタイプを置いても既存公開サイトのHTML・JSON・デプロイ処理は変更されません。

## 新サイトの基本構成

- `site/index.html` : AI編集版イベント一覧。23区フィルタ、キーワード検索、探索カバレッジ表示
- `site/copy.html` : コピペ用リスト。index と同一のフィルタ関数を使用
- `site/app.js` : 23区定義、日付計算、検索・絞り込みなどの共通ロジック
- `site/copy-contract.js` : コピペ契約 v1。項目順・フォールバックを固定
- `tools/validate_data.py` : JSON構造、23区探索状況、URL、重複、件数整合性を検証
- `tests/copy_contract.test.mjs` : コピペ出力順とフォールバックの自動テスト
- `docs/DESIGN.md` : AI探索・掲載判定・網羅性・監査設計
- `.github/workflows/deploy.yml` : 新リポジトリへ移した後に使う検証付きデプロイWorkflow（この隔離領域内では実行されません）

## コピペ契約 v1

既存サイトと同じ順序を固定します。

1. タイトル
2. 場所
3. 日時
4. 料金
5. 説明
6. 公式サイト
7. 情報元サイト
8. サムネイル画像URL（画像がある場合のみ）

フォールバックも既存仕様を維持します。

- タイトル: `name || url`
- 場所: `venue || ward`
- 日時: `period` + 時刻があれば全角スペース + `time`
- 料金: `price || （料金情報は公式サイトでご確認ください）`
- 公式サイト: `official_url || url`
- 情報元サイト: `source || ''`
- 画像URL: `image` がある場合だけ追加

一覧画面とコピペ画面は同じ `filterEvents()` を使い、日付・区・キーワードの条件をURLパラメータで引き継ぎます。これにより「一覧では10件なのにコピペでは11件」のような差分を防ぎます。

## 公開ゲート

新サイト側では、厳格モードの検証を通らないデータは公開しません。

- 23区すべてに探索ステータスがある
- 23区すべてが `checked` である
- イベントの `ward` が東京23区のいずれか
- 必須URLが `http://` または `https://`
- 重複イベントがない
- `coverage.published_count` と実イベント件数が一致
- サンプルデータではない
- コピペ契約テストが成功

## 別サイト化

最終的にはこのディレクトリの中身を、新しい独立リポジトリ（例: `tokyo-family-events-ai`）のルートへ移して GitHub Pages を有効化します。

既存サイトは従来の機械収集版として残し、新サイトをAI探索・編集版として並行運用します。
